# 🎯 Quiz App

Welcome to the **Quiz App**, a fun and interactive web application built with **React.js**.  
Users can enter their name, choose from multiple categories (like *Entertainment*, *Science & Technology*, *Sports & Games*, etc.), and test their knowledge through engaging quizzes. 
https://my-quiz-challenge.netlify.app/

---

## 🧠 About the Project

This Quiz App allows users to:
- Enter their name and select a quiz category.
- Answer multiple-choice questions dynamically loaded from a data file.
- View their final score and retake the quiz anytime.

It’s designed with a **clean, modern UI** using custom CSS and provides a smooth user experience.

---

## ✨ Features

✅ Simple and elegant UI  
✅ Multiple quiz categories  
✅ Instant feedback and scoring  
✅ Responsive design for all devices  
✅ Replay option to restart quiz
